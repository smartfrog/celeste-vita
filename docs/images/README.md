## `vita3k-first-room-historical.png`

- Unchanged historical first-room diagnostic rendered in Vita3K from revision
  `702e7f2dde9f6ad5c3f4e7ed981a46acbec09915`.
- Captured by the native guest using `glReadPixels` from `GL_BACK`, then converted

  decals during a climb capture. It is **not the current build** and does not
  validate physical Vita rendering, performance or full-game compatibility.
- PNG, 960 × 544 pixels.
